# Sellink 보안·검증 보고서

작성일: 2026-07-29

## 적용 항목

- 관리자·회원 로그인 계정/IP 이중 속도 제한
- 전체 API IP 기준 분당 600회 상한
- Redis 공유 카운터와 단일 인스턴스 폴백
- Bearer 세션 만료·로그아웃 토큰 폐기
- CORS 허용 출처 명시, CSP, HSTS, frame 차단, MIME sniffing 차단
- JSON 256KB, 웹훅 64KB 요청 제한
- capability 기반 서버 권한 검사
- 조직 재귀 범위와 TodoPay 매장코드 금융 범위
- 수수료 변경·권한 변경·출금 승인 OTP 재인증
- TOTP 시크릿 AES-256-GCM 암호화 및 조회 API 비노출
- 중요 변경 감사 로그와 요청 ID
- 수수료 변경 직렬화 잠금 및 원장 이벤트 멱등성

## 자동 검증 결과

- Sellink 단위/통합 테스트: 33/33 통과
- TodoPay 결제·원장 테스트: 24/24 통과
- 동시 동일 이벤트 정산: 최초 1건 반영, 후속 1건 중복 처리 확인
- 역분개 후 잔액 0 및 변경된 정책 버전 재적용 확인
- 50,000회 수수료 배분 보존 법칙 성능 스모크
- 20,000개 조직 노드 비재귀 순회 성능 스모크

## 남은 운영 검증

- 실제 ALB/WAF/Redis 환경의 부하 시험
- PG 운영 NOTI 재전송을 이용한 end-to-end 멱등성 시험
- TodoPay 매장코드 실데이터 매핑 후 역할별 교차 조회 침투 시험
- 운영 비밀 값 교체와 AWS Secrets Manager 접근 정책 확인
- 운영 배포 후 브라우저 기반 주요 화면 회귀 시험
